Tabletop Craft AR privacy policy

Last updated: [DATE]. Publisher: [PUBLISHER NAME]. Contact: [CONTACT EMAIL].

Tabletop Craft AR is a Meta Quest app that shows a Minecraft: Java Edition server's world as a miniature on your table, together with a server plugin you run on your own PC. It is open source: github.com/NickStassen/tabletop-craft-ar.

In short: there is no account, no advertising and no analytics of our own. The app talks to the Minecraft server you choose on your local network, and fetches player skin images from Minecraft's skin server. We (the developers) receive no data from the app.

What the app sends, and to whom

This is every network endpoint the app contacts.

WhereWhat and why
The Minecraft server you connect to, on your local network (a WebSocket, usually port 8765; the plugin accepts it only from private network addresses) The positions of your headset and controllers relative to the table, about 30 times a second (they move your "giant" in the game); the blocks you place or break, items you use, chat lines and server commands you send; the headset's name (for example "Quest 3") and the app version; after pairing, the device token that server gave this headset. From the server the app receives the world, player names and positions, chat, and the game's textures, models and sounds from the server owner's own Minecraft install.
Your local network, UDP broadcast to port 8765 A small "is there a Tabletop server here?" message when the app looks for servers. If none answers, the app tries to open a connection to port 8765 on the other addresses of your local network (it sends nothing to them) and lists the ones that answer.
textures.minecraft.net (Mojang / Microsoft), HTTPS The skin images of the players shown on the table, so they look like themselves. The server tells the app which images; the app only ever fetches images from this address. Like any web request, it shows your public IP address to that service.
Unity Technologies The Unity engine the app is built with may send anonymous hardware statistics (device model, operating system, graphics chip) when the app starts, under Unity's own privacy policy.
Meta (the headset's system software) The app uses Meta's passthrough and scene understanding to find your table. Your room's scene data is read on the headset and is not sent anywhere by the app. What the Quest system itself collects is covered by Meta's privacy policy.

Permissions

  • Spatial data (scene): to find the table you marked in Space Setup and put the miniature on it.
  • Internet and Wi-Fi state: to reach the server on your local network and the skin images, and to keep the Wi-Fi responsive (low-latency mode) while you play.

What is stored, and where

  • On the headset, in the app's own folder: the server address and your choices (table position, block size, hotbar, volume), the device tokens of the servers you paired with, and the game files your server sent. Uninstalling the app deletes all of it.
  • On the server owner's PC (not ours): the plugin keeps a list of paired headsets (name, a hash of each token, when it was paired and last seen, and an optional Minecraft player name), and the server log records headset connections with their local IP addresses, and commands run from a headset.
  • With us: nothing. We run no server for this app and receive no data from it.

Your choices and deleting data

  • Uninstall the app to delete everything it stored on the headset.
  • The server owner can remove a headset with tabletop unpair, and delete the plugin's devices.yml and the server logs.
  • Questions or requests: [CONTACT EMAIL]. As we hold no data about you, there is nothing for us to delete, but we will help you with the steps above.

Children

The app is meant for teens and adults (13 and older). It has no chat with strangers of its own: chat only reaches the players on the server you connect to.
